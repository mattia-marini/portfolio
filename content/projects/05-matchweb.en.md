<!-- compact -->A university project in full-stack web development using `Spring`, `HTML`, `CSS`, and `JavaScript`, simulating a betting site.<!-- /compact -->

The tech stack used is broadly the following:

- **REST API** (`Spring Boot`) — odds management, user accounts, match scheduling
- **Web frontend** — Thymeleaf templates, real-time score updates via WebSocket
- **Database** — H2 (in-memory)

Two separate repositories: `Team04_REST` for the backend API, and `Team04_MatchWeb` for the frontend.

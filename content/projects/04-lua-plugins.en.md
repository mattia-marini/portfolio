<!-- compact -->
Plugins written in `Lua` for the [Neovim](https://neovim.io/) text editor and the [Reaper](https://www.reaper.fm/) DAW.
<!-- /compact -->

The most notable ones are:

- [marini-fx-linker](https://github.com/mattia-marini/Marini-FX-linker) — a plugin for the Reaper DAW that allows seamless plugin configuration synchronization
- [moontex.nvim](https://github.com/mattia-marini/moontex.nvim) — a Neovim plugin providing the basic features needed to compile and work with `LaTeX` in a lightweight manner
- [runner.nvim](https://github.com/mattia-marini/runner.nvim) — a lightweight Neovim plugin providing a framework to efficiently compile and run different programming languages
- [silk.nvim](https://github.com/mattia-marini/silk.nvim) — a Neovim plugin that generates themes for common terminal utilities, allowing for consistent looks throughout the terminal
